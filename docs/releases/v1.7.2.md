# Crawlo v1.7.2 Release Notes

> 发布说明，用于 GitHub Release 页面。
>
> - **Tag**: `v1.7.2`
> - **版本**: `crawlo 1.7.2`
> - **基于**: `develop_distributed` 分支

---

## 🆕 新增功能

### 可观测性：Prometheus 集成
- 全新统计后端 `prometheus_backend.py`，支持将爬虫运行指标暴露为 Prometheus metrics
- 配套 Grafana Dashboard（`assets/grafana/crawlo-dashboard.json`），15 个面板可视化采集状态
- 指标前缀、端口、标签均可配置，支持与现有监控栈无缝对接
- 文档：`docs/guides/prometheus-integration.md`

### 分布式：Redis Sentinel 高可用
- 新增 `REDIS_SENTINEL_URLS` 配置项，支持 Redis Sentinel 哨兵集群
- `CrawloConfig.distributed()` 新增 `sentinel_urls`、`sentinel_service` 参数
- 与单点 Redis、Cluster 模式互相独立，按需启用

### 分布式：Redis 队列强化
- **原子 ACK**：队列消费确认走 Lua 脚本，避免重复消费
- **种子锁续期**：长时间运行的任务种子锁自动续期，防止误判过期
- **死信 CLI**：`crawlo.commands.dead_letter` 命令，管理死信队列

### 工程化：CI 持续集成
- 新增 `.github/workflows/test.yml`，GitHub Actions 自动跑核心单元测试
- Python 版本矩阵 `3.10 / 3.11 / 3.12 / 3.13`
- README 顶部增加 CI / PyPI / Python 版本徽章

### AI 集成：MCP Server 加固
- mcp 依赖锁定 `>=1.0,<2.0`（mcp 2.x 移除 `mcp.server.fastmcp`，避免启动崩溃）
- 浏览器下载日志重定向到文件，防止污染 MCP stdio 的 JSON-RPC 消息流
- 新增 24 个 MCP 测试，覆盖工具注册、三模式调用、错误码返回

---

## 🔧 修复

- **自适应选择器**：`from_dict` 对 `None` 字段容错；`_calculate_dict_diff` 防 `None` 崩溃；双阈值逻辑修正
- **Camoufox 下载器**：适配 v0.4+ 同步 API（`asyncio.to_thread`）；锁定版本范围避免 API 断裂
- **CloakBrowser 下载器**：移除已废弃的 `backend` 参数（v0.4.7+ 仅支持 Playwright）
- **Checkpoint**：先提取指纹再提取待处理请求，避免竞态丢数据
- **SPIDER_CLOSED 事件**：`close_spider` 异常时也正确触发
- **metrics_endpoint**：监听地址 `0.0.0.0` → `localhost`

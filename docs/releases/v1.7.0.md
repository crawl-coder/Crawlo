# Crawlo v1.7.0 Release Notes

> 发布说明，用于 GitHub Release 页面。
>
> - **Tag**: `v1.7.0`
> - **版本**: `crawlo 1.7.0`
> - **定位**: 首个正式版本发布预备

---

## 🆕 新增功能

### 分布式：Redis Stream 队列
- 全新的 `redis_stream_queue.py`（600+ 行），基于 Redis Stream 的高可靠任务队列
- **Task Tracker**（`task_tracker.py`）：任务进度跟踪与状态管理
- **种子锁机制**：防止多 Worker 重复消费同一任务
- Redis Stream 工具集（`utils/redis/stream_utils.py`）：Stream 操作封装

### 分布式：背压系统重构
- 重命名 `EngineBackpressureAdapter`，连接 `BACKPRESSURE_STRATEGY` 配置
- 修复背压策略无法按配置生效的问题
- Checkpoint 关闭时保存崩溃问题修复（2 个 bug）

### 分布式：完整测试体系
- 新增 L1 层测试（`tests/test_distributed_l1_*.py`）：
  - 队列、锁、消息、监控、进度、速率、注册表、Tracker、Failover
- `tests/test_distributed_quick.py`（213 行）快速冒烟测试
- `tests/distributed_test_plan.md`（371 行）分布式测试计划文档

### 其他
- Redis Stream 相关配置项完善
- 分布式架构文档更新

---

## 🔧 修复

- **背压系统**：策略配置不生效问题
- **Checkpoint**：shutdown 时保存被 2 个 bug 破坏的问题
- 分布式队列消费、锁竞争相关修复

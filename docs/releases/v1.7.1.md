# Crawlo v1.7.1 Release Notes

> 发布说明，用于 GitHub Release 页面。
>
> - **Tag**: `v1.7.1`
> - **版本**: `crawlo 1.7.1`
> - **定位**: 1.7.0 的功能完善与文档补全

---

## 🆕 新增功能

### 分布式系统完善
- **Redis Stream 队列**持续强化：`redis_stream_queue.py` 扩展 415+ 行
  - 孤儿待处理请求恢复机制（`test_orphan_pending_recovery.py`，705 行）
  - 全场景测试（`test_distributed_all_scenarios.py`，762 行）
- `max_concurrency` → `max_spiders` 重命名，新增 `redis_username` 支持
- 新增 `examples/ofweek_distributed/run_10_workers.py`（10 Worker 示例）

### 自适应选择器（P0+P1 优化）
- **`ignore_attributes`**：忽略指定属性，提升选择器稳定性
- **`find_similar`**：相似元素查找功能
- 提取 `ResponseAdaptiveMixin`：自适应选择器从 `response.py` 独立
- 4 项修复 + 全面测试（`test_adaptive_fixes.py` 237 行、`test_adaptive_find_similar.py` 196 行）

### MCP 模块 6 项优化
- 6 工具架构确认（fetch/extract/spider/evaluate/screenshot/status）
- screenshot 工具返回完整 base64 数据而非截断预览
- MCP 文档更新为 6 工具 + evaluate/screenshot 场景

### 调度器（定时任务）
- **任务级超时配置**：`timeout` 从全局配置移入 `SCHEDULER_JOBS` 任务级字段
- 全局新增 `SCHEDULER_JOB_TIMEOUT` 配置
- 调度器时间漂移修复

### Shell 与兼容性
- 新增 `crawlo shell` 使用指南
- Python 3.14 兼容层（`utils/py314_compat.py`）完善

---
